# Supplier Management Application

A Spring Boot MVC web application built for managing suppliers with full CRUD operations, input validation, and database persistence.

## Features
* **Full CRUD Operations:** Add, view, update, and delete supplier records seamlessly.
* **Input Validation:** Built-in form validation to ensure data integrity.
* **Database Persistence:** Connected via Spring Data JPA for reliable data storage.
* **MVC Architecture:** Organized following standard Model-View-Controller design patterns.

## Tech Stack
* **Backend:** Java, Spring Boot (Spring MVC, Spring Data JPA)
* **Frontend:** HTML5, Thymeleaf templates
* **Build Tool:** Maven
* **Database:** H2 / MySQL (configurable via `application.properties`)
